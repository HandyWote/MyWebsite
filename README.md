## 技术栈 | Tech Stack

- Backend: Go 1.25 + Gin + GORM
- Frontend: Next.js 16 + React 19 + MUI + Three.js
- Database: PostgreSQL + pgvector
- Deployment: Docker Compose with edge Nginx, Next standalone, and Go API

## 快速开始 | Quick Start

```bash
# Docker 部署 | Docker deployment
docker compose up -d --build

# 访问 | Access: http://localhost:4419
```
