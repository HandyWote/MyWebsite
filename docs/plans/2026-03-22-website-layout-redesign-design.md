# 网站前台布局重新设计文档

**日期**: 2026-03-22
**状态**: 已批准

---

## 1. 概述

重新设计网站前台布局，采用 TUI（终端用户界面）风格的 Terminal Aesthetics 设计系统，打造具有辨识度的个人网站。

### 目标

- **视觉焕新**: 深色终端风格，更精致、更有层次感
- **信息架构优化**: 清晰的三部分组织（关于我、文章、项目）
- **用户体验提升**: 侧边栏固定 + Tab 切换，直观的内容导航

---

## 2. 整体布局架构

```
┌──────────────┬──────────────────────────────────────┐
│              │  ~/articles $    ~/projects $       │
│   侧边栏      ├──────────────────────────────────────┤
│   关于我       │                                      │
│              │        主内容区                        │
│  ~ 头像      │    (Tab 切换显示文章列表               │
│  ~ 名字      │     或项目卡片)                       │
│  ~ slogan    │                                      │
│  ~ 社交链接   │                                      │
│  ~ 教育背景   │                                      │
│  ~ 技术栈     │                                      │
│  ~ GitHub    │                                      │
│    日历      │                                      │
│              │                                      │
└──────────────┴──────────────────────────────────────┘
```

### 技术实现

- 侧边栏固定（fixed），不随页面滚动
- 主内容区可滚动，Tab 切换内容
- 保持 Terminal Aesthetics 风格
- 侧边栏宽度: 280px（中等宽度）

## 3. TUI 风格设计规范

### 3.1 Box Drawing 字符

| 用途 | 字符 |
|------|------|
| 边框角 | `┌` `┐` `└` `┘` |
| 边框线 | `─` `│` |
| 分隔线 | `──` |
| 链接前缀 | `▸` |
| 选中指示 | `●` `○` |
| 终端提示符 | `$` |
| 光标 | `▮` |
| GitHub 日历 | `█` `▁` |

### 3.2 配色方案

沿用现有 Terminal Aesthetics 配色：

```css
--bg-primary: #0d1117;
--bg-secondary: #161b22;
--bg-tertiary: #21262d;
--accent-blue: #58a6ff;
--accent-green: #3fb950;
--text-primary: #f0f6fc;
--text-secondary: #8b949e;
--border-default: #30363d;
```

### 3.3 字体

- **等宽字体**: JetBrains Mono
- **中文字体**: Noto Sans SC

## 4. 侧边栏设计

### 4.1 视觉结构

```
┌─[~/handywote]──────────────────────────┐
│                                        │
│   ╔══════════════════╗                │
│   ║   [avatar]       ║  name@host     │
│   ║   [avatar]       ║  $ slogan ▮    │
│   ╚══════════════════╝                │
│                                        │
│   ──[ Social ]──────────────────────    │
│   ▸ GitHub                              │
│   ▸ Email                               │
│                                        │
│   ──[ Education ]─────────────────    │
│   ▸ 北京大学 (2022-2026)               │
│                                        │
│   ──[ Tech Stack ]─────────────────    │
│   [React] [Go] [TS] [Node] [Postgres] │
│                                        │
│   ──[ GitHub Activity ]────────────    │
│   ████████ ██████ ████ ██████         │
│   ████████ ██████ ████ ██████         │
│   ▁▁▁▁▁▁ ▁▁▁▁ ▁▁▁▁ ▁▁▁▁              │
│                                        │
└────────────────────────────────────────┘
```

### 4.2 内容组成

- **头像 + 名字 + slogan**: ASCII 风格边框包裹
- **Social**: GitHub、Email 链接，`▸` 前缀
- **Education**: 学校名称和在校时间
- **Tech Stack**: 技能标签芯片
- **GitHub Activity**: 简化版贡献热力图

## 5. Tab 切换组件

### 5.1 命令式路径风格

```
  ~/articles $        ~/projects $
```

- 当前选中：文字高亮 + `$` 后缀 + `▔▔▔▔▔` 下划线
- 未选中：文字变灰 + `○` 前缀

## 8. 动画与微交互

### 8.1 页面加载动画

Staggered Reveal（依次出现）:

| 元素 | delay |
|------|-------|
| sidebar-title | 0ms |
| social-links | 100ms |
| education | 200ms |
| tech-stack | 300ms |
| github-calendar | 400ms |
| tab-bar | 200ms |
| content-list | 300ms |

### 8.2 光标闪烁

```css
.cursor-blink {
  animation: blink 1s step-end infinite;
}
```

### 8.3 链接悬停

```css
a:hover::before {
  content: '▸ ';
  color: var(--accent-blue);
}
```

---

## 9. 响应式策略

| 断点 | 布局变化 |
|------|---------|
| ≥ 1024px | 侧边栏固定 280px + 主内容区 |
| 768-1023px | 侧边栏收缩为 200px |
| < 768px | 侧边栏变为顶部抽屉 |

## 10. 实施范围

### 前台页面

- `/` - 首页（新布局）

- `/articles/:id` - 文章详情（保持现有设计）

### 管理后台

保持现有设计，不在本次修改范围内。
